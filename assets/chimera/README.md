# Chimera artwork files

This directory holds the four images provided for the **Chimeras** entry in the Chronicles bestiary.

Upload the four .webp images with these exact names:
- chimera-gallery-1.webp — moonlit, black-and-violet feathered winged chimera
- chimera-gallery-2.webp — mountain winged chimera with purple feathered wings
- chimera-gallery-3.webp — winged chimera guardian reference sheet
- chimera-gallery-4.webp — full Chimera anatomy and character sheet

The bestiary script displays each of these files automatically once present.

These are concept visual references. The novels and Plu's Creatures manuscript remain definitive for the species' canon.
