WEBSITE IMAGE GALLERY UPLOAD

The gallery has been prepared, but is NOT yet published.

GitHub repository: https://github.com/jazmin072/Test

1. Open the repository main branch.
2. Click Add file > Upload files.
3. Extract this ZIP and drag the shared-moments.html file and all ten .webp files (NOT README.txt) to the root of the repository.
4. Commit the files to main.
5. After the Vercel deployment completes, visit https://chronicles-of-plu-and.vercel.app/shared-moments.html
6. Optionally add a link to /shared-moments.html in the existing Gallery section of index.html.

This preserves all current website artwork and creates a separate page for the new set.
